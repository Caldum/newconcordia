# Glosario: términos del juego y nombres en el código

El código, la base y los commits están en inglés; la interfaz, en español neutro. Esta tabla fija la
correspondencia. Si un término nuevo aparece en el código, se agrega aquí en el mismo PR.

| Juego (interfaz) | Código y base |
| --- | --- |
| Ciudadano, ciudadana | `citizen` |
| Ciudadanía | `citizenship` |
| Lista de espera | `waitlist` |
| País | `country` |
| Región | `region` |
| Dueño de la región | `owner` (`region_owner`) |
| País de origen de la región | `home_country` |
| Ocupada | `occupied` |
| En juego / fuera de juego | `active` / `inactive` |
| Territorio en disputa | `disputed territory` |
| Día de juego | `game day` (`game.game_day()`) |
| Reloj del juego | `game clock` (`game.now()`) |
| Tarea programada | `scheduled job` |
| Ejecución de una tarea | `job run` |
| Franja (de una tarea) | `slot` |
| Parámetros de balance | `balance_params` |
| Registro de administración | `admin_audit_log` |
| Oro | `gold` |
| Crédito | `credit` |
| Ración | `ration` |
| Arma | `weapon` |
| Combustible | `fuel` |
| Golpe | `hit` |
| Daño | `damage` |
| Batalla, ronda | `battle`, `round` |
| Energía | `energy` |
| Fuerza | `strength` |
| Rango | `rank` |
| Empresa, empleo, salario | `company`, `job`, `wage` |
| Tesoro | `treasury` |
| Congreso, congresista | `congress`, `congress_member` |
| Banca (escaño) | `seat` |
| Ley | `law` |
| Presidente, vicepresidenta | `president`, `vice_president` |
| Ministro del Interior | `interior_minister` |
| Adaptación (primeros 7 días) | `adaptation period` |
