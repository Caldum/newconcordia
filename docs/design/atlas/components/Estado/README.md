# Estado

Etiqueta corta de estado. Siempre lleva una palabra que se entiende sin el color; el color solo la refuerza.

- `at-estado-vivo` con `at-punto`: lo único que se anima por su cuenta en todo el juego (un pulso de 1,8 s, apagado con movimiento reducido).
- `at-estado-ok`, `-aviso`, `-info`, `-nacion`: con su tinte y su texto del mismo nombre.
- Texto en el estilo `chip` (13 px, 600). Es el único texto de 13 px permitido.
