# Status

A short status label. It always carries a word that is understood without the color; color only reinforces it.

- `at-status-live` with `at-dot`: the only thing in the whole game that animates on its own (a 1.8 s pulse,
  off with reduced motion).
- `at-status-ok`, `-warning`, `-info`, `-nation`: with the tint and text of the same name.
- Text in the `chip` style (13 px, 600). It is the only 13 px text allowed.
