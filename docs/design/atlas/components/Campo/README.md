# Campo

Campo de texto de 52 px con la etiqueta arriba, siempre visible.

- Borde `linea-control`; con foco, `info` y un halo suave.
- Error: `aria-invalid="true"`, borde `guerra` y una ayuda que dice qué pasó y cómo arreglarlo, con ícono. Nunca solo el borde rojo.
- Confirmación (nombre disponible, contraseña segura): `at-ayuda-ok` con ícono de check.
