# Stage

The dark surface that opens the home page and accompanies the Entry screens. It always shows something from
the game in progress (a battle, a region, a country), never a generic illustration.

- Background `ink`, padding `space-9`, headline in `display` and subtitle in `on-ink-muted`.
- At the bottom, the stripe with the 13 national colors (`country-*`), 6 px.
- On Entry it takes the left half at full height; the form goes on the right on `land`.
