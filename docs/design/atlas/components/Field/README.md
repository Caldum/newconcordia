# Field

A 52 px text field with the label above, always visible.

- Border `line-control`; on focus, `info` and a soft halo.
- Error: `aria-invalid="true"`, a `war` border and a hint that says what happened and how to fix it, with an
  icon. Never just the red border.
- Confirmation (name available, strong password): `at-hint-ok` with a check icon.
