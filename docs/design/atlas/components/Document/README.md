# Document

The reward moment of sign-up: the document the country hands over when the email is confirmed. It tilts
2.5° and enters with a single 450 ms animation (disabled with reduced motion).

- Header in `ink` with the country's official name as a place name; the country silhouette with the
  player's region marked.
- Fields: name, number (country code + sign-up order), region, date, level and starting gift.
