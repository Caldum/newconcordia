# Boton

El botón dice exactamente lo que pasa, empezando por el verbo: «Entrar a combatir», «Crear mi ciudadano». Nunca «Enviar» ni «Aceptar».

- `at-btn-principal` (tinta): la acción de la pantalla. Una por vista.
- `at-btn-guerra` (guerra): solo para combatir o abrir una batalla, como máximo uno por pantalla.
- `at-btn-secundario`: alternativas. Su borde usa `linea-control`.
- `at-btn-fantasma`: volver, cancelar y acciones de bajo peso.
- `at-btn-claro` y `at-btn-contorno-claro`: sobre `tinta` o sobre el escenario.
- `at-btn-grande` (56 px, `toque-principal`): el botón principal de las pantallas de Entrada y el de Golpear.
- Desactivado: `disabled` o `at-btn-off`, y el texto cambia para decir por qué («Ya trabajaste hoy»).

Lo que aporta quien lo usa: el texto, el ícono opcional (18 px, a la izquierda) y el destino (`a href`) o la acción (`button`). Alto mínimo `toque-min`, 44 px.
