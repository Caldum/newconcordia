# Pista

Barras de proporción y de progreso. Puntas de `radio-xs`, separación de 3 px entre bandos.

- Daño de una batalla: dos tramos con los colores nacionales y los porcentajes escritos debajo.
- Energía: rayo, pista `energia-pista` con relleno `energia` y el número al lado. Nunca la barra sola.
- Experiencia, presupuesto, cupo: un tramo en `tinta` sobre `#E1E7EC`.
