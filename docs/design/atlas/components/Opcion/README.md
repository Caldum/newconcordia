# Opcion

Opción grande para decisiones de una sola elección con contexto: dónde empezar, tipo de ataque, tipo de ley. Alto mínimo 72 px.

- Círculo de selección a la izquierda, después el color o la silueta, el nombre y una línea que ayuda a decidir.
- Opción no disponible: `disabled`, opacidad 55 % y el motivo en la línea de ayuda («Solo Economía o Congreso»).
