# Nota

Mensajes en la página. Cada uno lleva ícono y texto que explica qué pasó y qué hacer; nunca se disculpa.

- `at-nota-info`, `-aviso`, `-error`, `-ok`: dentro del flujo, junto a lo que explican.
- `at-aviso` (sobre tinta): confirmación breve de una acción («Cobraste 36,96 Crédito»). Como máximo 2 o 3 a la vez, y los repetidos se suman («+80 Crédito», no dos de +40).
