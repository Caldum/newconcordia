# Note

Messages on the page. Each one carries an icon and text that explains what happened and what to do; it never
apologizes.

- `at-note-info`, `-warning`, `-error`, `-ok`: inside the flow, next to what they explain.
- `at-toast` (on ink): a brief confirmation of an action («Cobraste 36,96 Crédito»). At most 2 or 3 at once,
  and repeated ones add up («+80 Crédito», not two of +40).
