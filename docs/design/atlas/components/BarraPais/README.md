# BarraPais

Barra superior de la app, teñida con el color del país del jugador (`nacion`). Para alguien de España sería roja; para Brasil, verde.

- Izquierda: marca y secciones. La sección actual en `tinta` con `aria-current="page"`.
- Derecha: Oro, Crédito, energía, avisos y perfil, cada uno sobre `tierra`.
- Alto `barra-alto`, 68 px. No se usa en las pantallas de Entrada.
