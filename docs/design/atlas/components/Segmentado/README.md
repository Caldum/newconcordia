# Segmentado

Control segmentado para cambiar de vista dentro de una pantalla (capas del mapa, filtros, monedas) e interruptor para ajustes que se activan o desactivan.

- El segmentado cambia lo que se ve, nunca guarda nada. Hasta 4 opciones.
- El interruptor aplica el cambio en el momento y lleva `aria-label` con el nombre del ajuste.
