# Silhouette

Real geometry from the game map (Natural Earth, simplified) for countries and regions. It is the main graphic
element of Atlas; illustrations stay for the section headers.

- Country in play: filled with its `country-*`. Occupied region: with the occupier's color.
- In battle: a hard gradient from bottom to top, the defender up to its percentage and the attacker the rest.
- Country not in play: only the dotted outline in `line-control`.
- Always with its name nearby, as a place name. The silhouette alone is not enough to identify it.
- The files are in `docs/design/assets/silhouettes/`.
