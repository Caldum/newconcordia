# CountryBar

The app's top bar, tinted with the player's country color (`nation`). For someone from Spain it would be red;
for Brazil, green.

- Left: brand and sections. The current section in `ink` with `aria-current="page"`.
- Right: Gold, Credit, energy, notices and profile, each on `land`.
- Height `bar-height`, 68 px. Not used on the Entry screens.
