# Silueta

Geometría real del mapa del juego (Natural Earth, simplificada) para países y regiones. Es el elemento gráfico principal de Atlas; las ilustraciones quedan para las cabeceras de sección.

- País en juego: relleno con su `pais-*`. Región ocupada: con el color del ocupante.
- En batalla: degradado duro de abajo hacia arriba, el defensor hasta su porcentaje y el atacante el resto.
- País fuera de juego: solo el contorno punteado en `linea-control`.
- Siempre con su nombre cerca, en topónimo. La silueta sola no alcanza para identificar.
- Los archivos están en el grupo de recursos Siluetas.
