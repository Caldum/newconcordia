# Documento

El momento de recompensa del registro: el documento que entrega el país al confirmar el correo. Se inclina 2,5° y entra con una sola animación de 450 ms (desactivada con movimiento reducido).

- Cabecera en `tinta` con el nombre oficial del país en topónimo; silueta del país con la región del jugador marcada.
- Campos: nombre, número (código de país + orden de registro), región, fecha, nivel y regalo de inicio.
