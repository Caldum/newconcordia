Silhouettes of the 13 countries in play and of the disputed regions, from the game map geometry (Natural
Earth, public domain). Countries come in their `country-*` color; standalone regions in `ink` (#13202E) to be
tinted in code; `argentina-cuyo-occupied` shows Cuyo in Spain's color; `uruguay-inactive` is a dotted outline
in `line-control`. Always paired with the place name.
