# D05 review

Review of `feat/d05-accounts` against `docs/plans/d05-accounts.md` (`requesting-code-review`,
`differential-review`, `sharp-edges`, `accessibility`, `react-best-practices`). Size: large; strategy:
focused on the trust boundary between Auth, the citizen trigger and the browser.

| Area | Risk | Notes |
| --- | --- | --- |
| Citizen trigger on `auth.users` | High (runs inside every sign-up) | Security definer with `search_path = ''`; validates name, country and language before inserting; any failure rolls back the sign-up (pgTAP checks that no account is left). Metadata is never read for authorization. |
| Name reservations | Medium | Released after 24 h unconfirmed or with the same 256-bit `signup_key`; a confirmed name is never released and never changes (pgTAP). The key lives only in the tab's session storage and in the account's own metadata. |
| API surface | High (permissions) | New callables: `check_citizen_name` (anon, names are public), `create_my_citizen` and `get_my_citizen` (authenticated, scoped to `auth.uid()`). Catalog audit: no other grants; invariant tests still pass. |
| CAPTCHA | High | Enforced by Auth on sign-up, sign-in, recovery and resend; CI runs Auth with Cloudflare's test secret and an e2e check that a sign-up without a token gets `captcha_failed`. |
| Email links | Medium | Token hash plus `verifyOtp` (works across devices); each token is verified once even under StrictMode. Redirects limited to the allow list in Auth. |
| Session storage | Medium | «Mantener la sesión» switches between local and session storage; storage errors fall back without breaking sign-in. A new password signs out other sessions. |
| Accessibility | Medium | Labels on every field, errors tied with `aria-describedby` and announced as alerts, focus moves to the first wrong field, password toggle with `aria-pressed` on the label row (no overlap with the input, axe target-size passes). axe passes on landing, sign-up, verification and sign-in in the e2e journeys; no horizontal scroll at 360 px. |
| Performance | Medium | All account screens are lazy routes. supabase-js now loads on the first screen: initial JS 163.7 of 170 kB (ADR 0006 notes the follow-up). |

Findings fixed during review: the password toggle covered the input (axe target-offset), the «Olvidé mi
contraseña» link was below 24 px, email templates depended on the redirect including the path, duplicate alert
roles around error notes, flags missing on the landing.

Accepted: no terms checkbox until legal texts exist; leaked-password check left to the hosted Auth setting;
Turnstile hostname and action are not checked by Auth (the widget's hostname list in Cloudflare applies).
