# D06 review

Review of `feat/d06-citizenship` against `docs/plans/d06-citizenship.md` (`requesting-code-review`,
`differential-review`, `sharp-edges`, `accessibility`). Size: large; strategy: focused on who can change whose
citizenship and on the clock-driven rule.

| Area | Risk | Notes |
| --- | --- | --- |
| Request decisions | High (permissions) | `decide_citizenship_request` checks that the caller holds `president` or `interior_minister` of the destination; the requester cannot decide their own request (pgTAP). Only pending requests can be decided, under a row lock. |
| Approval effects | High (game state) | One function applies every approval (rule, waitlist, office, timeout): new country, number and capital, offices left, waitlist entry cleared. Numbers come from a per-country counter row, so concurrent approvals get distinct numbers (unique index as backstop). |
| 72-hour rule | Medium | Hourly job, idempotent per slot, `for update skip locked`; pgTAP pins the clock at 71 and 72 hours. E2E backdates one request and runs an unused slot so it never touches other data. |
| API surface | Medium | New callables: waitlist count and country rules (anon, public numbers), own waitlist, own request, request, cancel, list and decide (authenticated, scoped to `auth.uid()` or to the office). No table grants. |
| Migration locks | Low | Squawk lock warnings acknowledged per statement: `countries` is static and `citizens` is empty in the hosted projects. `get_my_citizen` is dropped and recreated with more columns; the web ignores unknown columns. |
| Accessibility | Medium | Waitlist select labeled with its error tied by `aria-describedby`; decisions announced in a status region; approve and reject buttons name the player; axe passes on the new screens in the journeys. |

Findings fixed during review: the Google citizen creation raced with its own «already has a citizen»
redirect; `Date.now()` during render replaced by a stable `useNow()`; `status` output column ambiguous inside
`request_citizenship`.

Accepted: approvals can be up to one hour late (hourly job); the document shows the flag instead of the
silhouette (ADR 0007).
