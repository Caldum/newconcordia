# L5 review

Review of `feat/l5-terms-moderation-beta` against `docs/plans/l5-terms-moderation-beta.md`.
Size: medium; strategy: who can see what (reports, messages), then the sign-up gate.

| Area | Risk | Notes |
| --- | --- | --- |
| Message privacy | Medium | Only the recipient can report a message, and only moderators read reported ones; hidden messages lose their text for both players. |
| Moderation power | Medium | Every decision and every un-hide goes in the admin log with before and after; nothing is deleted. |
| Report spam | Low | One open report per target and reporter, 20 a day. |
| Closed beta | Medium | Enforced in the one function every sign-up path uses; admins are always allowed. |
| Legal | High (owner) | The texts are drafts and the minimum age is unset: both must be decided before a public beta. |

Accepted: the acceptance screen is a web gate; actions do not check acceptance in the database.
